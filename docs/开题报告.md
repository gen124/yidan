# PatchMIL-3D 开题报告（详细版）

> 题目：面向小样本3D医学影像的Patch级多实例学习与迭代重标框架，以及图结构可解释性方法

## 1. 研究背景与科学问题
- 医学影像（如QSM、T1 MRI）在患者级别常只有二分类标签（有/无病变），缺少体素或Patch级细粒度标注；小样本、弱监督成为常态。
- 科学问题1：如何在仅有患者级标签下学习到具备定位能力的Patch级判别特征，并将其聚合为稳健的患者级决策？
- 科学问题2：在弱监督与小样本条件下，如何获得可信、可解释的病灶定位与致病路径证据，并将其可视化给临床？

对应挑战：
- 标注弱：缺少实例（Patch）级真值；
- 数据少：几十到百例，易过拟合；
- 3D高维：Patch抽取、显存/计算开销大；
- 可解释性：需从Patch到解剖区域/通路的多层次解释。

## 2. 相关工作简述
- 多实例学习（MIL）：将患者视作“包（bag）”，Patch为“实例（instance）”；经典池化如max/mean、注意力MIL等。
- 弱监督定位：CAM/Grad-CAM、注意力图，用于从分类模型中提取显著区域。
- 图神经网络与医学知识：将解剖结构建图，引入先验知识（解剖邻接、白质纤维束）以提升可解释性与稳健性。
- 我们在本项目中融合：Patch级分类器 + MIL聚合 + 迭代重标（提高实例标签质量）+ 解释器（图结构），形成端到端的“从Patch到患者、从判别到解释”的一体化方案。

## 3. 方法总体框架
- 数据与Patch：将3D体积裁切为大小为 [48,48,32] 的Patch（可调），步长等于或小于Patch尺寸；每个Patch初始继承患者标签作为伪标签。
- 四阶段训练流程（见 `train.py`）：
  1) 预训练：用伪标签训练Patch分类器（ResNet3D骨干，见 `models_patch.py`）。
  2) 迭代重标（K轮）：用当前模型对全部Patch打分，选择高置信正/负样本重标，更新训练集再微调。
  3) 阶段4.1 冻结骨干：仅训练分类头，稳定优化。
  4) 阶段4.2 解冻骨干：小学习率联合训练，获得最终性能。
- MIL聚合：将Patch级分数聚合为患者级概率，用于验证与最终推理；同时也是解释的基础。
- 可解释性：
  - Patch级显著性/热图（由分类器与聚合权重间接得到）；
  - 图层解释（`explainer.py`, `graph_builder.py`）：将Patch映射到超体素/解剖区域，构图后用GNN解释重要通路。

## 4. 核心计算方法与数学表述
### 4.1 Patch分类与损失
- 给定患者体积 X，裁得 N 个Patch：{x_i}_{i=1..N}，患者标签 y∈{0,1}。
- Patch分类器 f_θ 输出 logits z_i=f_θ(x_i)，概率 p_i=σ(z_i)。
- 预训练使用伪标签 y_i=y：最小化二元交叉熵
$$\mathcal{L}_{pre} = -\frac{1}{B}\sum_{i\in\text{batch}} [y\log p_i+(1-y)\log(1-p_i)]$$

### 4.2 MIL聚合（注意力示例）
- 学习注意力权重 a_i = softmax(g_φ(x_i))，患者级概率：
$$ s = \sum_i a_i\, p_i, \quad a_i=\frac{\exp(g_φ(x_i))}{\sum_j \exp(g_φ(x_j))} $$
- 患者级损失：
$$ \mathcal{L}_{bag} = -[y\log s + (1-y)\log(1-s)] $$
- 实现上项目可采用简单池化或注意力模块（当前版本以Patch分类 + 验证阶段聚合为主）。

### 4.3 迭代重标（提高实例标签质量）
- 用当前模型对训练集全部Patch打分得 p_i；根据阈值 τ_h, τ_l 进行重标：
$$ \tilde{y}_i = \begin{cases}1, & p_i>\tau_h\\0, & p_i<\tau_l\\\text{保持伪标签 }y, & \text{otherwise}\end{cases} $$
- 重新构建数据集，用 \(\tilde{y}_i\) 继续训练，迭代 K 轮（`train.n_relabel_iters`）。
- 阈值选择当前默认 τ_h=0.8, τ_l=0.2，可随数据分布调节。

### 4.4 训练稳定性与工程加速
- 数据加载：`num_workers`、`prefetch_factor`、`persistent_workers` 配合使用；
- 显存/吞吐权衡：自动试跑估计单样本显存占用，合理扩大 batch（`auto_tune_batch_and_workers`）。
- AMP混合精度：`train.amp=true`，大幅降低显存，提升吞吐；
- 无缓冲日志：`PYTHONUNBUFFERED=1 python -u`，实时观察训练阶段与进度；
- 评估指标：`metrics.py` 中 `compute_metrics(y_true, y_prob)`，AUC/ACC/Precision/Recall/F1。

## 5. 实现与代码结构（与仓库一致）
- `data_utils.py`：
  - `PDVolDataset` 读取 `data/train_manifest.csv`, `data/val_manifest.csv`，做基本预处理与数据增强；
  - `PatchDataset` 切 Patch，输出 `volume(1,C,H,W,D), label, patient_id, patch_idx`。
- `models_patch.py`：
  - `ResNet3D_PatchClassifier`：3D卷积骨干 + 分类头；
  - `PatchMILAggregator`：可扩展的MIL聚合（若使用）；
  - `build_patch_model(cfg)`：根据配置构建模型。
- `train.py`：
  - 四阶段训练主流程；
  - `auto_tune_batch_and_workers()`：单次试跑估显存并给出 batch/workers 建议；
  - `train_epoch()/evaluate()`：AMP+DataLoader优化；
  - `infer_patch_scores()/relabel_patches()`：迭代重标；
  - 输出 `metadata.json`、阶段检查点 `*.pth` 到 `outputs/<run>/`。
- `explainer.py`, `graph_builder.py`：
  - 基于SLIC超体素与解剖区域建图；
  - GNN解释多条重要路径（top-k）。
- `metrics.py`：统一封装 AUC/ACC/Precision/Recall/F1。（注意调用顺序 `compute_metrics(y_true, y_prob)`）

## 6. 创新点（novelty）
- 弱监督下的“实例质量提升”闭环：预训练→模型打分→高置信重标→再训练，逐轮提升伪标签质量与定位能力。
- 分阶段稳定优化：冻结骨干→小步解冻，适配小样本与不稳定伪标签分布，降低过拟合风险。
- 工程与可复现实践：自动显存估计与批量/并行度调优、无缓冲日志、稳健的DataLoader配置，适应多GPU/多CPU环境。
- 可解释性贯穿：Patch级显著性 + 图层解释，连接影像信号与解剖结构/通路，输出可读的临床证据。

## 7. 实验设计与评估方案
- 数据划分：训练/验证按患者划分（当前 252/64），保证独立同分布。
- 评估指标：患者级 AUC/ACC/Precision/Recall/F1；补充Patch级定位的定性可视化评估。
- 消融实验：
  1) 无迭代重标 vs 1/2/3 轮重标；
  2) 冻结-解冻策略 vs 一次性联合训练；
  3) 不同阈值（τ_h, τ_l）的敏感性分析；
  4) MIL聚合策略（max/mean/attention）。
- 资源与效率：记录每 epoch 训练/验证时长，GPU/CPU 利用率；对 DataLoader 并行与 batch 大小进行吞吐曲线对比。

## 8. 风险与对策
- Worker 崩溃/数据I/O瓶颈：合理设置 `num_workers/prefetch_factor/persistent_workers`，必要时降低并行；
- 显存不足：降低 `train.batch_size` 或 Patch尺寸；开启 AMP；
- 重标误差放大：采用保守阈值并逐步收紧；在 bag-level 约束下联合优化；
- 过拟合：分阶段训练、数据增强（翻转/旋转/强度扰动）、早停与权重衰减。

## 9. 两个拓展构思（第二点暂未实现，给出方案）
### 构思A：不确定性驱动的自适应重标（可实现）
- 动机：固定阈值在不同病型/扫描条件下并不鲁棒。
- 方法：为每个 Patch 估计不确定性（如 MC Dropout、温度标定后的方差），按不确定性加权或动态调整阈值：
$$
\tau_h(x) = \bar{p}(x) + k\,\sigma(p),\quad \tau_l(x) = \bar{p}(x) - k\,\sigma(p)
$$
- 预期收益：减少误重标，提升后续训练稳定性与最终AUC。

### 构思B：图注意力MIL（Graph-Attentional MIL）与跨模态先验（未实现，概念设计）
- 目标：在聚合阶段引入图结构先验（解剖邻接/纤维束连接），学习图注意力以建模Patch间关系，从而更好地从“少量关键实例”中抽取证据。
- 方案：
  - 图构建：将Patch映射到超体素节点；根据空间邻近与分割图/模板构建边；
  - 图注意力：用 GAT/Transformer-style 注意力在图上聚合节点特征，输出 bag-level 表征；
  - MIL目标：bag-level BCE，同时可联学节点级注意力作为解释；
  - 跨模态融合：将QSM/T1/AAL等通道作为多模态特征或边权先验。
- 评估：与当前池化/注意力MIL进行AUC与定位对比；可解释性通过路径重要性验证。

```bash

# 后台运行
nohup env PYTHONUNBUFFERED=1 python -u train.py \
  --config config.yaml \
  --out_dir outputs/patch_mil_v1 \
  > outputs/patch_mil_v1/train.log 2>&1 &
```

```yaml

  batch_size: 24
  num_workers: 8
  prefetch_factor: 4
  persistent_workers: true
  amp: true

  patch_stride: [48,48,32]

  n_relabel_iters: 3
  high_conf_threshold: 0.8
  low_conf_threshold: 0.2
```
